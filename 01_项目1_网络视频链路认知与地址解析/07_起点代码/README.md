# 网络视频链路认知与地址解析｜起点代码

URL五字段解析、媒体信息读取和链路报告。

## 使用位置

请在项目目录运行命令，不要把文件复制到其他目录后单独执行。共享视频位于 `../data/passage.mp4`。

## 示例入口

```bash
python 07_起点代码/url_parser.py --url rtmp://127.0.0.1:1935/course/cam_g01
```
