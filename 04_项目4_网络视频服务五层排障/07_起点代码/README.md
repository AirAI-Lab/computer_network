## 使用位置

请在项目目录运行命令，不要把文件复制到其他目录后单独执行。共享视频位于 `../data/passage.mp4`。

## 示例入口

```bash
python 07_起点代码/diagnose.py --container zlm_g01 --host 127.0.0.1 --port 1935
```
