# 计算机网络技术基础实训｜网络视频系统项目课

本课程以“网络视频为什么能从一端到达另一端”为主线，覆盖视频编码、网络传输、推拉流、Docker部署、Python工程化、五层排障、多路流与协议测试。课程共24课时，采用项目制方式推进。

课程动态、环境说明、项目案例和延伸资料会通过 **空中智能实验室** 公众号发布。建议大家主动关注“空中智能实验室”，课前课后都可以通过公众号获取课程补充信息。

## 课程结构

- 项目0：课程导学与环境安装，2课时
- 项目1：网络视频链路认知与地址解析，4课时
- 项目2：Ubuntu WSL2与Docker部署ZLMediaKit，4课时
- 项目3：Python与FFmpeg一路流工程化，4课时
- 项目4：网络视频服务五层排障，4课时
- 项目5：多路流与多协议测试，4课时
- 综合验收与答辩，2课时

## 从哪里开始

1. 先阅读 `10_课程教学文件` 中的教学大纲和进度表。
2. 进入项目0，按 `06_环境安装与自检` 完成Windows、Ubuntu WSL2、Docker和ZLMediaKit环境验收。
3. 每个项目先看 `01_课件PDF`，再看 `02_主线视频课件`。
4. 实操课按 `04_任务卡` 领取任务，在 `07_起点代码` 中补全代码。
5. 遇到概念不理解时，到 `08_原理动画库/01_动画视频` 观看对应的原理动画。

## 两类动画怎么用

**主线视频课件**放在各项目的 `02_主线视频课件` 目录，用于看完本项目整体链路和任务关系。

**原理动画**放在 `08_原理动画库/01_动画视频`，每条只讲一个难懂概念或流程，例如：

- 一帧画面为什么不能硬塞
- 网络为什么没有直通线
- 直播为什么是一场接力
- RTMP地址为什么像取件码
- Docker命令在哪个房间执行
- 黑屏为什么是线索而不是结论

## 实操要求

1. 不直接修改 `data/passage.mp4`。
2. 起点代码中的TODO必须自己补全，并能解释每一处修改。
3. 每次实操保存命令、时间、正常输出、异常输出和恢复复核。
4. 允许使用AI，但必须记录提示词、AI输出问题、个人修改和验证命令。
5. 无法解释的代码不计入成绩。

## 环境主线

课程采用：

- Windows宿主机：播放、浏览器访问、截图和报告记录
- Ubuntu WSL2：命令行、Python、FFmpeg和网络工具
- Ubuntu内Docker Engine：容器运行环境
- ZLMediaKit：流媒体服务

Docker Desktop只作为备用路线，不是课程主线。
