# 多路流与多协议测试｜起点代码

双路身份隔离、协议矩阵和资源证据。

## 使用位置

请在项目目录运行命令，不要把文件复制到其他目录后单独执行。共享视频位于 `../data/passage.mp4`。

## 示例入口

```bash
python 07_起点代码/protocol_matrix.py --config 07_起点代码/multi_stream_config.json --output evidence/protocol_matrix.csv
```
