# multi_stream_config.json字段说明

|字段|类型|必填|作用|常见错误|
|---|---|---|---|---|
|streams|数组|是|多路流配置列表|为空或不是数组|
|input|字符串|每行必填|输入媒体路径|某一路路径写错导致整套启动失败|
|server|字符串|每行必填|服务地址|多路流误写不同主机导致现象不可比|
|port|整数|每行必填|RTMP端口|协议矩阵误用该端口生成HTTP地址|
|httpPort|整数|每行必填|HTTP服务端口|写成1935|
|app|字符串|每行必填|应用分组|不同组混用同名app|
|stream|字符串|每行必填|流身份|重复stream导致现象覆盖|
|log|字符串|每行必填|该路日志|所有流写同一日志难定位|

## 测试要求

1. 启动前先检查身份唯一。
2. 启动后保存PID清单。
3. 生成协议矩阵并逐项实测。
4. 每项结果必须写pass/fail和reason，不能只写“可以”。
