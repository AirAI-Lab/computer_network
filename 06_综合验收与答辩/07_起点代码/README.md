# 综合验收与答辩｜起点代码

自动验收、项目报告、提交包和答辩材料。

## 使用位置

请在项目目录运行命令，不要把文件复制到其他目录后单独执行。共享视频位于 `../data/passage.mp4`。

## 示例入口

```bash
python 07_起点代码/acceptance_check.py --root .. --output evidence/acceptance.json
```

## 要求

- 起点版按TODO补全。
- 每次运行后保存命令、时间、关键输出、异常和恢复复核。
- 允许使用AI，但必须记录提示词、AI输出问题、个人修改和验证命令。
- 直接提交无法解释的代码不计入成绩。
