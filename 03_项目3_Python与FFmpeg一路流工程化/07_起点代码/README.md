# Python与FFmpeg一路流工程化｜起点代码

配置化推流、进程日志和媒体列表监测。

## 使用位置

请在项目目录运行命令，不要把文件复制到其他目录后单独执行。共享视频位于 `../data/passage.mp4`。

## 示例入口

```bash
python 07_起点代码/stream_controller.py start --config 07_起点代码/stream_config.json
```
